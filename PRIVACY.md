# Privacy

The current LAN Transfer Core prototype does not include accounts, telemetry,
cloud storage, analytics, or remote relay services. File transfers are initiated
by the user between devices on the same local network. The application does not
intentionally send file contents or transfer history to the project maintainers.

The application writes received files to a local folder selected by the user.
Network discovery, diagnostics, and any future optional online features must be
documented before they are introduced. Third-party components remain subject
to their own licenses and privacy/security documentation.
